THREAT ANALYSIS REPORT
=======================
Classification: TLP:AMBER
Date: 2024-06-15
Analyst: Security Research Team
Reference: TR-2024-0615-001

EXECUTIVE SUMMARY
-----------------
This report details a sophisticated cyber espionage campaign attributed to
the APT29 threat group (also tracked as Cozy Bear, Midnight Blizzard, and
NOBELIUM), targeting government agencies and technology companies across
North America and Europe. The campaign, observed between January and June
2024, utilizes a multi-stage infection chain combining spear-phishing,
custom malware loaders, and novel C2 infrastructure.

The threat actors leveraged CVE-2023-23397 (Microsoft Outlook privilege
escalation) and CVE-2024-21413 (Microsoft Outlook remote code execution)
as initial access vectors, followed by deployment of previously undocumented
malware tracked as ENVYSCOUT and HALFRIG.

TECHNICAL ANALYSIS
------------------

Initial Access (TA0001):
Attackers sent targeted phishing emails containing malicious .RDP files
to high-value targets within government ministries and diplomatic entities.
The RDP files, when opened, established connections to actor-controlled
infrastructure, enabling credential harvesting and file system access.

Observed Techniques:
- T1566.001: Spearphishing Attachment
- T1566.002: Spearphishing Link
- T1190: Exploit Public-Facing Application
- T1078.004: Cloud Accounts

Execution (TA0002):
Post-compromise, the actors deployed PowerShell scripts and leveraged WMI
for lateral movement and data collection.

Observed Techniques:
- T1059.001: PowerShell
- T1047: Windows Management Instrumentation
- T1204.002: Malicious File

Persistence (TA0003):
The group established persistence through registry Run keys and OAuth
application abuse in compromised Microsoft 365 tenants.

Observed Techniques:
- T1547.001: Registry Run Keys / Startup Folder
- T1098: Account Manipulation
- T1136: Create Account

Defense Evasion (TA0005):
Actors employed Golden SAML techniques and disabled endpoint security tools
to evade detection.

Observed Techniques:
- T1550: Use Alternate Authentication Material
- T1562.001: Disable or Modify Tools
- T1656: Impersonation

Command and Control (TA0011):
C2 communications were routed through residential proxy networks and
compromised VPN appliances. Notably, the group used the Notion API as a
novel C2 channel to blend with legitimate traffic.

Observed Techniques:
- T1090.002: External Proxy
- T1573: Encrypted Channel

ATTRIBUTION
-----------
This campaign is attributed to APT29 (also known as Cozy Bear, Midnight
Blizzard, NOBELIUM, The Dukes, UNC2452) with HIGH confidence based on:

1. TTP overlap with previous SVR-attributed operations
2. Infrastructure patterns matching known APT29 operational infrastructure
3. Targeting profile consistent with Russian foreign intelligence priorities
4. Use of custom malware families (ENVYSCOUT, HALFRIG) unique to this group

MITIGATION RECOMMENDATIONS
--------------------------
1. Apply security updates for CVE-2023-23397, CVE-2024-21413, CVE-2022-27924,
   and CVE-2023-42793 immediately
2. Block all IP addresses and domains listed in the IOCs section at network
   perimeter firewalls and web proxies
3. Deploy MFA using FIDO2 hardware tokens for all privileged accounts
4. Monitor OAuth application consent grants in Microsoft 365 tenants
5. Implement application control to block execution of untrusted executables
6. Deploy EDR solutions with detection rules for the listed IOCs
7. Conduct threat hunting exercises using the ATT&CK techniques listed above
